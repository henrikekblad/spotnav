SpotNav 1.0.9 shows how far a charge has come. Install `spotnav-1.0.9.apk` over the existing app; settings, held prices and paired chargers are kept.

## What changed

- While a paired charger charges, the charger card shows a slim progress bar under the status with how far the charge has come and when it is expected to be done ("62 % done · done about 14:35"; "93 % of target" for a target level). The bar's stripes drift slowly while current flows, stand still when the charge is paused, and never move when animations are removed in the system settings. A solar or hybrid charge follows the sun, so it shows the percent without an end time; a Start with the car's level unknown shows the charging power instead.
