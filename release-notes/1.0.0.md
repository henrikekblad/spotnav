SpotNav 1.0.0 is the first release under the app's new name and package, `se.sensnology.spotnav`.

## Upgrading from an earlier version

Earlier versions (1.5.2 and older) used the package `se.sensnology.elpris`. Android treats the new package as a different app, so it does not replace the old one:

1. Note your price area and any taxes or fees you had set.
2. Remove the old widget from the home screen and uninstall the old app.
3. Install `spotnav-1.0.0.apk` below, add the widget again and set your price area.

Settings are not carried over. The old version is no longer maintained.

## What SpotNav does

- A home-screen widget and price table with today's and tomorrow's electricity spot prices for the Nordic and Baltic countries, Germany and the Netherlands, in 15-minute or hourly resolution, with VAT, energy tax and grid fee if you want them.
- An EV charging planner that finds the cheapest periods before your departure. It plans only on published prices and waits for tomorrow's prices instead of guessing.
- Optional pairing with the [SpotNav integration for Home Assistant](https://github.com/henrikekblad/spotnav-home-assistant), which then plans and controls your charger; the app shows its plan and status and changes its settings.
